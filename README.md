# Netflix Data Analysis

This project explores the Netflix Titles dataset using Python to understand patterns and trends in Netflix movies and TV shows.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## What I Worked On

- Data understanding
- Data cleaning
- Handling missing values
- Handling duplicate values
- Data type conversion
- Feature engineering
- Exploratory Data Analysis (EDA)
- Data visualization
- Correlation analysis
- Business insights

## Analysis Performed

- Movies vs TV Shows
- Top content-producing countries
- Content added over the years
- Most common content ratings
- Popular genres
- Release year distribution
- Movies and TV Shows added year-wise
- Relationship between release year and genre count
- Correlation between numerical features
- Outlier detection

## Key Insights

- Movies are more common than TV Shows.
- The United States produces the most content in the dataset.
- Netflix content additions increased significantly after 2015.
- TV-MA is the most common rating.
- Drama and International Movies are among the most common categories.
- Most Netflix content in the dataset consists of relatively recent releases.

## Conclusion

This project helped me practice the complete data analysis workflow, from cleaning and transforming raw data to exploring patterns, creating visualizations, and generating meaningful insights.
